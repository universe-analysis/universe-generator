Reading guide (added 2026-07-29). Superseded pages carry a dated Editor's note at the bottom; the era boundaries are: through 07-01 — hard-wall model with the edge-weighted/smart frequency sampler (wall-era numbers like the 2.46 count exponent are obsolete; runs before 07-06 also stopped ~2× shallow, absolute N ~5% low). 07-02 to 07-08 — the torus model arrives (current geometry), but the smart sampler remains until 07-09 (it produced at least one spurious trend, refuted 07-08) and phases are opt-in from 07-05. 07-09 onward — the current model definition (uniform-only sampler, always-on phases, maxfreq = T); results from here need no era translation. 07-25 onward adds the full-spectrum model (terms = T), a distinct variant alongside the 2-term legacy model — both are current. The canonical statement of current results is the repository README; on any disagreement, the README wins.
