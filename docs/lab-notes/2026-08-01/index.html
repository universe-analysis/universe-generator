Maximum knottable strands by dimension: the observed sequence is 2, 8, 24 — the hypercube-edge conjecture, doubled

Documentation of Chris's braid-mode observations (2+1 braid viewer, docs/viewers/twoplusone_braids.html, census-closure machinery) · STATUS: tooling-assisted observations, not a census-proved bound — no automated verification has been run

The maximum number of unique paths that can form a stable knot in d spatial dimensions was originally conjectured as 1, 4, 12, 32, 80 for d = 1–5 (README, knots/braids section) — which is exactly d·2d−1, the edge count of the d-dimensional hypercube. Subsequent hands-on exploration has revised the measured values upward by exactly a factor of two at every dimension probed so far:

  • 1+1: 1 → 2 (07-18 era exploration, “possibly, unverified”)
  • 2+1: 4 → 8 (Chris, 2026-08-01, via the braid viewer's closure/knot mode)
  • 3+1: 12 → 24 (07-18 era exploration, “possibly, unverified”)

The revised sequence 2, 8, 24 (, 64, 160 if the pattern holds at d = 4, 5) is d·2d — the DIRECTED edge count of the d-hypercube: the original conjecture with each undirected contact split in two. The natural physical reading of the factor 2 is chirality/orientation — each geometric contact slot admits an over-crossing and an under-crossing variant, which the braid picture resolves and plain intersection counting does not; that is presumably why the braid mode is where the doubling shows up.

Caveats, stated plainly: all three values are exploratory observations, none is verified by an automated census; the 07-18 lab note (the B₃ class census) is often cited for the 2 and 24 but does not itself contain any capacity measurement. A proper verification — sweep the 2+1 subpath dumps for the largest genuinely-knotted closure component and check that 8 is attained while 9 is not — is queued.
